Progetto scolastico di quarta informatica.

Piattaforma web per monitoraggio dati urbani come qualità dell’aria, traffico ed energia.

## Tecnologie
- HTML, CSS, JavaScript
- PHP
- MySQL
- Chart.js

## Funzioni
- Dashboard interattiva
- Grafici dinamici
- Simulazione dati smart city
